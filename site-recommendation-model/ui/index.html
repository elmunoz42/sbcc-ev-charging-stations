FROM IMAGE TO OPPORTUNITY

How this explorer works.

  1. Read the images.

    Existing Street View images are joined to their collection GPS metadata. Images without coordinates are excluded from the map.

  2. Look for diagonal parking.

    The preview uses existing dataset labels. Run model analysis to use the saved MobileNetV2 classifier instead. The model’s class 0 is diagonal parking, so diagonal probability is 1 minus its raw output.

  3. Find candidate locations.

    A location becomes a candidate if any of its images has a diagonal-parking label, or a model probability at or above your threshold. For model results, the highest image probability ranks the location. This is a screening score, not a feasibility estimate.

  4. Check the site.

    Review the image, open its coordinates in Google Maps, and export the shortlist. Pins show collection coordinates, which may differ from the photographed parking bays.

The existing model was trained on heavily imbalanced data and has limited diagonal-parking recall. Review both positive and negative predictions before drawing planning conclusions.

To enable the embedded Google map, configure GOOGLE_MAPS_BROWSER_API_KEY in your environment or .env, enable the Maps JavaScript API, and restart the server. Use a browser key restricted to your site’s referrers.
